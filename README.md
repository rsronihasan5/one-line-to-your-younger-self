An entry for the [One Line to Your Younger Self](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76) bounty on [make.fun](https://make.fun).

`main.py` (Python standard library only) writes exactly one line — the line
its writer would send back to their younger self — to `/output/entry.txt`,
validating the gate inside the program: 1–200 characters, a single line,
not only whitespace.

## The line

> Kid, eat the lunch your mother packed even when the other boys laugh — one day you'll pay good money for food that never tastes like home again.

## Run

```sh
python3 main.py
```
